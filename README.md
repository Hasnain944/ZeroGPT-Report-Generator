# ZeroGPT-Style AI Content Report Generator

A web-based AI Content Report Generator that analyzes submitted text and generates a structured, professional report with an AI-generated content percentage and human-written content percentage.

## Overview

The ZeroGPT-Style AI Content Report Generator is designed to provide a simple and user-friendly interface for generating AI content analysis reports.

Users can enter text, adjust the report settings, and generate a report that presents the analysis results in a clean, PDF-ready format.

## Features

- **Text Input:** Enter or paste text for report generation.
- **File Upload:** Upload a text file for processing.
- **Adjustable AI Percentage:** Set the AI-generated content percentage according to the required report configuration.
- **Human-Written Percentage:** Automatically reflects the remaining percentage.
- **Report Generation:** Generate a structured report based on the provided content.
- **PDF Export:** Download the generated report as a PDF.
- **Multi-Page Support:** Supports reports containing multiple pages.
- **Page Numbering:** Displays page numbers in the `1 / 11` format.
- **Report Footer:** Includes a small brain icon and page numbering.
- **Clickable Website Link:** The ZeroGPT logo/option links to the official ZeroGPT website.
- **Clean Interface:** Simple layout with a report-style presentation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML-to-PDF generation libraries

## How to Use

1. Open the application in your web browser.
2. Enter or upload the text you want to use.
3. Configure the AI percentage.
4. Generate the report.
5. Review the generated report.
6. Download the report in PDF format.

This is an independent ZeroGPT-style report generator and is not an official ZeroGPT product.

The generated percentages are configurable report values. They should not be considered verified AI-detection results or a substitute for analysis by an actual AI-detection service.
